# 테스트 범위와 결과

2026-11-15 macOS / Node.js v26.8.1: 버튼 메뉴·통합 재생 화면 수정 후 198개 테스트 통과. 우사기 이름·추임새·중복 접두사 방지와 기존 서명 프로토콜 유지도 검증합니다. 새 테스트는 카드 폼·버튼 재전송·허용 목록·캐시 표시의 이스케이프·정지 확인·재생 전용 임시 키의 권한·iframe 출처 검사·선택적 공개 제목 조회를 검증합니다. 실제 Google Chat 메뉴·신청 폼·카드 갱신과 로컬 통합 YouTube 재생도 해당 테스트 계정에서 확인했습니다. TV 연결·다른 계정의 실제 권한·장시간 광고 재생은 별도 검증 대상입니다.

2026-11-14, Windows / Node.js v24.22.1에서 `node --test` 실행.

v0.3의 189개 테스트가 모두 통과했습니다. 최신 결과는 GitHub Actions의 `tests` 집계와 아래 CI 링크를 확인하세요. 실제 Google 계정, API 키, 실제 TV는 사용하지 않았습니다. CI는 플랫폼별 JUnit 보고서도 제공합니다.

로컬 샌드박스에서는 loopback 접속과 임시 파일 rename이 제한되어 실패했으며, 로컬 테스트 실행 권한으로 재실행하여 통과했습니다. 테스트를 건너뛰어 통과시킨 것은 아닙니다.

## Apps Script 중계 검증

Code.gs를 Node VM에서 Properties/Lock/Cache/Utilities/ContentService 모의 API와 실행했습니다. HMAC 변조·재전송·시간창·거부 기본값·일반/래퍼 이벤트·임대/ACK·한글 용량·사용자별 결과·권한·일시 장애·리디렉션을 검증합니다. 실제 loopback HTTP로 서명된 요청→Apps Script 런타임→로컬 큐→결과 조회 왕복도 수행합니다. 실제 Google 배포 정책·Chat 등록·Cloud 결제 상태는 모의 테스트로 판정할 수 없습니다.

## 추가 검증 영역

- 대기열 동시 요청, 중복, 최대 개수, 만료, 저장 복원, 손상 파일 보존.
- 브라우저 재생 상태, 오래된 종료 이벤트, 자동재생 차단, 영상 오류, 단일 재생기 lease, 재연결 복구.
- 실제 로컬 HTTP 연결에서 인증/권한/Origin/JSON/크기/경로 제한 및 전체 신청-재생 이벤트 흐름.
- 실제 로컬 WebSocket에서 upgrade 검증, 분할 JSON, ping/pong, 응답 시간 초과, 연결 종료.
- WebSocket 마스크, 16/64비트 길이, TCP 분할, 과도한 크기, 잘못된 제어 프레임.
- Google 이벤트 두 형식, bot 무시, space/user 검증, 오래된 요청, 응답 outbox/재전송, ACK 순서.
- 이전 Pub/Sub 모듈의 RSA 서명·scope별 토큰 캐시 회귀 테스트 (현재 실행 경로에서는 사용하지 않음).
- 유튜브 URL 호스트 검증, API 키 없는 URL 신청, 검색 필터/캐시, 할당량 오류 처리.
- 실제 CLI 프로세스 실행, 무작위 토큰 생성, 설정 덮어쓰기 방지, 설정 검증, 진단 출력, HTTP 서버 시작부터 신청곡 저장까지.
- TV 코드 숫자 검증, 고정 HTTPS endpoint, 분할 UTF-8 이벤트, 잘못된 길이·JSON 차단, 연결 동시 실행 직렬화, 명령 오프셋 순서, 불확실한 명령 재전송 방지.
- 같은 영상을 두 번 신청할 때 새 nonce 요구, 요청 영상과 다른 상태 무시, 실제 playing 이후 같은 nonce의 ended만 처리, 외부 영상 변경 시 복구 대기.
- 실제 자체 서명 TLS 서버에서 잘못된 지문에 HTTP 요청 0건 확인. 일치한 인증서만 WebSocket upgrade 허용. 인증서/키는 테스트 실행 중 메모리에서 생성.
- 결과 오류 격리, 임시 오류 백오프, 느린 응답 중 로컬 제어 유지, 동시 flush 중복 방지. 이전 Pub/Sub 모듈의 구독 지속도 회귀 테스트로 유지.
- 곡별 브라우저 플레이어 콜백 격리, 상태 ACK 유실 재시도, 재생 정보 없는 오류 영상, 동일 영상의 이전 콜백, 운영자 pause/resume.
- fsync/이전 백업, 중복 서버 잠금, 손상 잠금 보존, 상태 백업 복구, 이전 어댑터 복원.
- Apps Script 사전 검사: 서명·허용 목록·버전 확인, 인증 실패와 비밀 값 비노출. 이전 Google 사전 검사도 회귀 테스트로 유지.
- 1,500단계 고정 시드 연속 시험: 중복·동시 신청, 종료, 일시정지, 취소, 만료, 재시작 후 대기열/기록의 ID 유일성과 보존 조건 확인.

CI는 GitHub-hosted Windows/Linux + Node 24에서 같은 테스트를 실행합니다. CI 성공도 하드웨어 호환성 검증은 아닙니다.
