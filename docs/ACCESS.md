# 접근 범위

## 실행 프로그램

| 대상 | 필요한 접근 |
|---|---|
| 로컬 파일 | 프로젝트 설정 및 설정된 data 폴더. 키와 연결 정보는 Git 제외 |
| 로컬 HTTP | 기본 127.0.0.1:8787. 관리자와 재생기 토큰 분리 |
| Google | 설정된 Apps Script 웹 앱 하나로 서명된 HTTPS 요청. 허용 Chat space의 앱 멘션 수신 |
| YouTube 검색 | 서버의 API 키로 검색. URL 신청은 키 없이 사용 가능 |
| YouTube TV 코드 | 본인이 코드로 연결한 화면. 고정 YouTube HTTPS endpoint |
| 삼성/LG 직접 제어 | 사용자가 설정한 기기 주소 하나와 현장 연결 승인 |
| Android HA | 지정한 Home Assistant 주소와 remote 엔티티 |

프로그램은 브라우저 프로필·쿠키·로그인 DB를 읽지 않습니다. 데스크톱 앱 제어, 네트워크 전체 탐색, 자동 포트포워딩, OS 서비스 설치, 관리자 권한 상승, 자동 방화벽 변경을 구현하지 않았습니다. 프로세스 잠금은 이 서버의 잠금 파일에 기록된 PID만 생존 확인하며, 감독기는 자신이 생성한 자식 프로세스만 종료합니다.

Google 중계 인증은 로컬 설정과 ScriptProperties에만 보관한 별도 공유 비밀로 수행합니다. Apps Script의 OAuth 범위는 빈 배열이며 Gmail·Drive·Sheets·외부 요청 범위가 없습니다. 서비스 계정 JSON 키나 브라우저 쿠키를 사용하지 않습니다. 웹 앱 Anyone 접근이 조직 정책상 허용되어야 하며, 서명 없는 호출은 거부합니다. `check-google`은 배포·인증·허용 목록을 확인하고 nonce 캐시만 기록합니다. [설정과 비용 경계](APPS-SCRIPT.md)를 참고하세요.

LAN의 다른 기기에서 재생 페이지에 접속할 때만 host와 네트워크 정책을 의도적으로 변경합니다. 일반 HTTP에는 암호화가 없으므로 신뢰된 네트워크 또는 HTTPS 프록시가 필요합니다. 노트북 HDMI 방식은 기본 loopback 연결로 운영할 수 있습니다.

## 개발 작업

저장소의 [AGENTS.md](../AGENTS.md)는 파일·로컬 테스트·해당 GitHub 저장소를 개발 범위로 정합니다. 로그인 웹 설정은 해당 브라우저 탭/사이트 접근이 명시적으로 연결된 경우에 진행하도록 규칙을 둡니다. 이는 개발 작업 규칙이며 운영체제나 도구 호스트의 강제 권한 격리를 대체하지 않습니다.
