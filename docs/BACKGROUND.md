# 신청곡이 없을 때 계절 배경음악

`config.local.json`의 `background.enabled: true`로 켭니다. 기본 예제는 꺼짐입니다. 실제 자동 대기열 관측을 지원하는 브라우저·YouTube TV 코드 어댑터에 적용합니다. 검색 API 키나 새로운 Google 권한은 사용하지 않습니다.

한국 시간 기준 3~5월은 봄, 6~8월 여름, 9~11월 가을, 12~2월 겨울입니다. 새 배경곡을 선택할 때 현재 연도와 계절을 계산하므로 제목에 `[자동 BGM · 2026 가을]`처럼 표시합니다. 연도 표시는 현재 계절의 운영 표시이며 해당 영상이 그해 발매된 신곡이라는 의미가 아닙니다. 기본 카탈로그는 재즈/피아노 연주 영상 2개씩이고 곡이 실제로 끝나면 다음 후보를 순환합니다. 계절이 바뀌어도 재생 중인 곡을 갑자기 자르지 않으며 다음 배경곡 선택부터 적용합니다.

## 동작

- 신청곡이 없고 일시정지·복구·오류 상태가 아닐 때 배경곡 한 곡을 시작합니다. 배경곡은 사용자 대기열·개인 신청 한도를 차지하지 않습니다.
- 우사기 배경곡의 실제 playing이 확인된 상태에서 새 신청이 들어오면 배경곡을 양보시키고 신청곡을 먼저 재생합니다. 여러 곡 신청은 기존 FIFO 순서를 유지합니다. 배경곡 전송 확인 중에 들어온 신청은 실제 playing 확인 뒤 우선 전환합니다.
- 신청곡이 모두 실제 종료된 뒤 다시 배경곡을 선택합니다. YouTube 추천 자동재생은 계속 비활성화합니다.
- 일시정지는 배경곡과 자동 시작도 보류합니다. **정지**는 현재 곡/대기열을 비운 뒤 배경음악도 꺼진 상태를 저장합니다. **계속** 또는 새 신청을 받으면 이 정지 보류가 해제됩니다. 일시정지는 계속 명령이 필요합니다.
- TV에서 누군가 직접 다른 영상을 선택하면 복구 대기로 전환하고 자동으로 덮어쓰지 않습니다. 수동 재생을 마치고 우사기로 돌아오려면 운영자가 **다음**을 누릅니다. 대기곡이 있으면 신청곡, 없으면 계절 BGM이 시작됩니다.
- 재시작은 기존 곡/대기열을 보존하며 동일 TV 재생을 관측해 복구합니다. 현재 곡이 불확실하면 배경곡도 자동 재전송하지 않습니다.
- HTTP 성공·곡 길이·경과 시간으로 실제 재생이나 종료를 확정하지 않습니다. 기존 CPN/playing/end 또는 실제 빈 상태 반복 관측을 사용합니다. 통신 실패나 확인 시간 초과는 오류 상태에 남기며 무한 재시도하지 않습니다. 브라우저의 확정된 재생 불가 오류는 기존 연속 3회 제한으로 일시정지합니다.
