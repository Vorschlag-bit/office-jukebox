# 곡명 검색 API — 배포 준비

2026-11-16: 전체 플리 기능은 실행 서버와 Apps Script에 적용했습니다. 검색 보완 코드는 별도 준비 브랜치에만 저장하며 실행 서버 재시작이나 Apps Script 코드 반영은 하지 않습니다. 키 저장과 별개로 search.enabled를 꺼 둡니다. 실제 검색 호출 검증 및 활성화는 별도 작업입니다.

## 준비된 사용 흐름

비공개 신청창 → 곡명 입력 → **곡명 검색** → 잠시 후 **내 신청 결과 · 비공개** → 최대 5개 후보 중 **＋ 신청**. 선택 버튼은 본인 결과에만 표시하고 검색 결과는 5분간 유효합니다. 다른 방·다른 사용자의 후보를 선택할 수 없습니다. 검색 접수는 재생 확인이 아니며, 선택곡은 기존 대기곡 뒤에 추가됩니다. 기존 `검색 <곡명>` → `선택 <번호>`와 웹 검색도 같은 API 경로를 사용합니다.

동일 검색 1시간 캐시, 동시 동일 요청 합치기, 10초 연결 제한, 64KB 응답 제한, 중복 영상 제거, 검색 제목 줄바꿈 정리, API 키/활성화/할당량 오류 안내를 구현했습니다. 할당량 오류 뒤 60초간 새 검색 호출을 쉬며 URL 신청과 기존 대기열 재생은 유지합니다. 서버 재시작 시 캐시와 이 짧은 대기 시간은 초기화됩니다. 브라우저 재생은 임베드 가능 필터를 적용하고 TV 앱 검색은 해당 필터를 적용하지 않습니다. 검색 결과라도 지역·연령·권리·기기 제한으로 재생이 불가능할 수 있습니다.

## 활성화 순서 — 운영자 작업

1. 기존 Google Cloud 프로젝트에서 **YouTube Data API v3**를 활성화합니다. Chat API와는 별개입니다. 결제 계정 연결이나 유료 서비스 추가는 이 작업 범위에 포함하지 않습니다.
2. Google Cloud **API 및 서비스 → 사용자 인증 정보**에서 API 키를 준비합니다. 키의 API 제한은 **YouTube Data API v3**로 제한합니다. 이 프로그램은 노트북 서버에서 요청하므로 웹사이트 HTTP 리퍼러 제한을 적용하면 실패할 수 있습니다. 고정 출발지 IP가 있는 환경은 그 IP 제한을 검토합니다. 키는 채팅에 보내거나 저장소에 올리지 않습니다.
3. 실제 실행 설정 `config.local.json`의 `youtubeApiKey`에 키를 저장합니다. 파일 수정만으로 현재 실행 중인 서버가 검색을 활성화하지는 않습니다. 다른 토큰·TV 연결 설정은 변경하지 않습니다.
4. 서버를 재시작하기 전에 아래 독립 검사로 확인합니다. 기본 검사는 API를 호출하지 않으며 `--live`만 실제 검색 1회를 사용합니다. 두 명령 모두 TV 명령·서버 시작·대기열 쓰기를 하지 않습니다.

```sh
node bin/check-search.js
node bin/check-search.js --live "아이유 밤편지"
```

5. 실제 검색이 통과하면 `search.enabled`를 `true`로 설정합니다. 키만 저장해서는 검색이 켜지지 않습니다. 보안 수정이 포함된 최신 준비 브랜치를 사용하고 Node 24.22.3 이상(24 계열) 또는 26.13.1 이상(26 계열)을 사용합니다. 기존 대기열을 백업하고 서버를 정상 종료한 뒤 준비 브랜치 코드로 재시작합니다. Apps Script에도 그 브랜치의 `apps-script/Code.gs`를 저장하고 기존 웹 앱 배포를 새 버전으로 갱신합니다. Chat 연결이 Head를 사용한다면 저장한 코드도 즉시 적용되므로 테스트 준비가 되었을 때 업데이트합니다. OAuth 범위는 추가하지 않습니다.
6. 비공개 신청창에 곡명을 입력해 검색하고 결과 버튼으로 한 곡을 신청합니다. 대기열 끝에 정확히 한 번 추가되는지 확인합니다. 키 오류 시 설정을 복구하고, 기존 URL 신청과 재생이 유지되는지 확인합니다.

## 할당량과 근거

2026-11-16 확인한 [Google 공식 할당량 문서](https://developers.google.com/youtube/data/determine_quota_cost)는 기본 검색 한도를 하루 100회로 안내하며 태평양 시간 자정에 초기화합니다. 실제 프로젝트의 Cloud 콘솔 할당량을 우선 확인합니다. 자동완성이나 주기적 검색은 하지 않으며 사용자가 검색할 때만 요청합니다. 할당량은 금액과 다른 개념이며 이 문서는 계정 전체의 비용을 보장하지 않습니다.

[공식 검색 API](https://developers.google.com/youtube/data/reference/rest/v3/search/list)를 사용하며 키는 서버에만 저장하고 `x-goog-api-key` 헤더로 보냅니다. 리디렉션은 따르지 않습니다. 이는 [Google API 키 권고](https://docs.cloud.google.com/docs/authentication/api-keys-best-practices)를 따릅니다. 브라우저 쿠키·유튜브 로그인·검색 스크래핑은 사용하지 않습니다.
