# 실사용 완료 조건

현재 판정: **소프트웨어 자동 검증 완료 / 실제 Google 연결과 물리적 TV 검증 미실시**.

소프트웨어 테스트 성공만으로 프로젝트의 실제 운영 성공을 선언하지 않습니다. 아래 항목을 사용하는 계정과 기기에서 확인해야 합니다.

| 단계 | 통과 조건 | 현재 |
|---|---|---|
| 로컬 코드 | 전체 자동 테스트와 Windows/Linux CI 통과 | 로컬 통과, 최신 CI는 Actions 확인 |
| Google 인증 | `check-google`에서 구독과 허용 공간 접근 성공 | 계정 설정 필요 |
| Chat 수신 | 테스트 공간의 앱 멘션 → 접수 응답 → 정확히 한 번 대기열 추가 | 미실시 |
| 영상 지정 | 영상 A와 B를 각각 요청하고 실제 해당 영상·소리 확인 | 미실시 |
| 연속 재생 | 실제 종료 이벤트로 A → B가 한 번만 전환 | 미실시 |
| 제어 | 일시정지·계속·다음·정지·취소가 실제 화면과 일치 | 미실시 |
| 복구 | 서버 재시작/네트워크 중단 후 원치 않는 중복 재생 없이 복구 | 미실시 |
| 장시간 | 최소 1시간 및 광고 포함 재생에서 메모리/절전/연결 문제 없음 | 미실시 |
| 대안 | 기본 앱 실패 시 실제 재생을 정지하고 browser+HDMI 경로로 전환 가능 | 미실시 |

## 가장 짧은 현장 순서

1. 기기의 제조사·모델·OS·펌웨어·YouTube 앱 버전 확인.
2. 기본 앱에서 TV 코드 연결이 보이면 `pair-tv`로 연결.
3. 정확한 URL 두 개를 신청하여 화면·소리·상태·자동 전환 확인.
4. nonce 이벤트가 없거나 앱 호환성이 안 맞으면 수동 다음 곡을 확인하고 browser+HDMI 대안을 시험.
5. Google Chat을 연결하고 동일한 두 곡 시험을 채팅 명령으로 반복.
6. 네트워크 끊김과 서버 재시작을 시험하고 복구.
7. 1시간 이상 운영 후 아래 기록을 작성.
