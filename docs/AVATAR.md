# 우사기 헤드폰 프로필 이미지

`public/avatar-headphones.png`는 음악을 듣는 우사기 프로필 후보 1번입니다. 사용자가 이 이미지를 봇 프로필로 선택했습니다. 기존 웹 화면의 `avatar.png`는 그대로 유지합니다.

[원본 이미지 모음](https://chiikawawallpaper.com/zh-Hans/mobile-wallpaper/usagi)의 [헤드폰 배경 그림](https://r2.chiikawawallpaper.com/wallpaper/wallpaper/role/20250828170130_e5980628650c678d01db6405efae5d1b-900.jpg)을 참고해 내장 이미지 편집 도구로 정사각형에 맞췄습니다. 원본 픽셀의 단순 자르기와는 다릅니다. 캐릭터와 원본 그림의 권리는 각 권리자에게 있습니다.

Chat API 구성의 아바타 URL은 해당 파일의 commit 고정 HTTPS 주소로 설정합니다. 정사각형 PNG이며 기존 앱 이름·배포·권한 설정은 변경하지 않습니다. Space의 이모지 아이콘과 Chat 앱 프로필은 별개입니다.
