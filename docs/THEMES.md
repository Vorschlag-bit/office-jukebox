# 세 가지 음악방 테마

홈과 `/queue`의 **오늘의 음악방 꾸미기**에서 선택합니다.

- 우사기: 기존 노란 간식방과 여러 우사기 그림을 유지합니다.
- 치이카와: 딸기우유 분홍색, 세로 줄무늬 헤더, 둥근 디저트 카드와 치이카와 그림입니다.
- 하치와레: 맑은 파란색, 구름 헤더, 비대칭 둥근 카드와 하치와레 그림입니다.

선택은 해당 브라우저·동일 출처의 localStorage에 저장합니다. 같은 출처의 홈/플리 탭은 변경을 즉시 반영하고 새로 열어도 유지합니다. IP 주소와 이름 주소는 서로 다른 출처이므로 이름 주소로 통일하는 편이 좋습니다. 다른 컴퓨터의 테마는 바꾸지 않습니다. 저장이 차단되면 이 탭에서만 적용합니다. 테마 선택은 제어 API를 호출하거나 재생 iframe을 재생성하지 않습니다. Chat 봇의 프로필과 말투는 그대로입니다.

배경 원본을 편집하거나 확대 저장하지 않고 로컬 제공합니다. 화면을 흐리게 덮던 반투명 색상 막을 제거했고, 카드 배경은 읽기 쉽게 유지합니다.

- 치이카와: 3840×2161 별과 디저트 사이에서 다양한 표정을 짓는 치이카와 패턴. [게시 페이지](https://chiikawawallpaper.com/ja/desktop-wallpaper/chiikawa) · [원본](https://r2.chiikawawallpaper.com/wallpaper/desktop/20260516/ac687546be5b1ed160220430094f0632.jpg)

## 캐릭터 말투

치이카와는 짧은 감탄과 머뭇거림(와아…/응…/에헤헤…), 하치와레는 발견·공감·되묻는 말투(그런 거구나/~라는 거야?!/뭔가 좋은 느낌)를 한국어 창작 문구로 반영합니다. 공식 대사의 고정 번역은 아닙니다. [애니 공식 소개](https://www.anime-chiikawa.jp/)와 [하치와레 표현 해설](https://realsound.jp/book/2026/09/post-2530646.html)을 참고했습니다.

홈 제목·소개·대기 안내·연결·검색 안내·재생 상태·오류/복구·정지 확인·푸터와 Queue의 상태·연결·주소 복사 안내에 적용합니다. 신청 결과는 각 테마별 6가지 상황에 3개씩 18개 반응을 사용하되 서버가 보낸 원문과 오류 코드는 그대로 보존합니다. 상태 폴링은 무작위 문구를 바꾸지 않습니다. 테마 변경 시 이미 표시된 상태와 결과도 다시 표현하며, 곡명/검색 결과/오류 원문은 바꾸지 않습니다. 미확인 재생을 재생 중으로 표현하거나 오류가 해결됐다고 표시하지 않습니다. 버튼 명령과 정지 시 대기열 삭제 안내는 유지합니다. Chat 봇과 독립 재생기의 기존 우사기 말투는 이 웹 테마 변경에 영향을 받지 않습니다.

## 한국어 말투 세부 조정

하치와레는 결론을 먼저 말하고 대상을 뒤에서 덧붙이는 호흡을 사용합니다. 예: “발견했어? 좋아하는 노래”, “기대된다, 다음 곡도!”. `고거·고냥·고런`은 상황에 맞게 직접 작성하며 모든 `그` 글자를 기계적으로 바꾸지 않습니다. “고거잖아, 고거!!” 같은 되짚기와 친구에게 말을 거는 리듬을 섞었습니다.

치이카와는 긴 문장을 더듬는 방식에서 짧은 감탄·호흡(응… / 와…아…! / 으으…) 중심으로 바꾸었습니다. 필요한 사용법은 괄호 안 안내로 따로 적습니다. 페이지 제목·대기·연결·복구·주소 복사·신청 안내·검색 후보 안내·결과 반응에 반영합니다. 곡 제목, 서버 결과 원문, 오류 코드와 재생 상태의 불확실성은 그대로 보존합니다.

[공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html)와 한국어 팬 말투 사례([고거·되짚기](https://www.inven.co.kr/board/maple/5974/7295049), [고냥·고래](https://gall.dcinside.com/mgallery/board/view/?id=chiikawa&no=6396&page=1)), [치이카와의 짧은 발화 정리](https://chiikawa.fandom.com/ko/wiki/치이카와)를 참고했습니다. 사용자의 도치·발음 선호를 함께 반영한 창작 UI 문구이며 공식 대사나 고정 번역이라고 주장하지 않습니다.
