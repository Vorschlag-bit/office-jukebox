# 세 가지 음악방 테마

홈과 `/queue`의 **오늘의 음악방 꾸미기**에서 선택합니다.

- 우사기: 기존 노란 간식방과 여러 우사기 그림을 유지합니다.
- 치이카와: 딸기우유 분홍색, 세로 줄무늬 헤더, 둥근 디저트 카드와 치이카와 그림입니다.
- 하치와레: 맑은 파란색, 구름 헤더, 비대칭 둥근 카드와 하치와레 그림입니다.

선택은 해당 브라우저·동일 출처의 localStorage에 저장합니다. 같은 출처의 홈/플리 탭은 변경을 즉시 반영하고 새로 열어도 유지합니다. IP 주소와 이름 주소는 서로 다른 출처이므로 이름 주소로 통일하는 편이 좋습니다. 다른 컴퓨터의 테마는 바꾸지 않습니다. 저장이 차단되면 이 탭에서만 적용합니다. 테마 선택은 제어 API를 호출하거나 재생 iframe을 재생성하지 않습니다. Chat 봇의 프로필과 말투는 그대로입니다.
